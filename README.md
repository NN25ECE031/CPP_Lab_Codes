# C++ Object-Oriented Programming Lab

A collection of C++ programs completed as part of the **Object-Oriented Programming in C++ Laboratory (ECE121)** during the 2026–27 academic year.

The repository contains solutions to the **Do-It-Yourself (DIY) exercises** given in the lab manual, organized week-wise for easy reference.

##  Course

**Course:** Object-Oriented Programming in C++
**Course Code:** ECE121
**Department:** Electronics & Communication Engineering
**Academic Year:** 2026–27

The lab covers the transition from procedural C++ programming to object-oriented programming and modern C++ concepts.

##  Lab Topics

| Week | Topic                         | Main Concepts                                                      |
| ---- | ----------------------------- | ------------------------------------------------------------------ |
| 01   | From C to C++                 | References, `std::string`, namespaces, type-safe I/O               |
| 02   | Functions                     | Function overloading, default arguments, inline functions          |
| 03   | Classes & Objects             | Classes, objects, encapsulation, `this` pointer                    |
| 04   | Constructors & Dynamic Memory | Constructors, destructors, deep copy, dynamic memory               |
| 05   | Static & Friend               | Static members, static functions, friend functions/classes         |
| 06   | Operator Overloading          | Arithmetic, comparison, stream, unary and subscript operators      |
| 07   | Inheritance                   | Single, multilevel, hierarchical, multiple and virtual inheritance |
| 08   | Polymorphism                  | Virtual functions, abstract classes, runtime polymorphism          |
| 09   | Exception Handling            | `try`, `throw`, `catch`, custom exceptions, stack unwinding        |
| 10   | File I/O                      | File streams, reading/writing files, CSV-style data                |
| 11   | Templates & STL               | Function/class templates, `vector`, `map`, `queue`, etc.           |
| 12   | STL Algorithms & Lambdas      | `sort`, `find_if`, `count_if`, `accumulate`, `priority_queue`      |
| 13   | Modern C++                    | Smart pointers, Factory/Singleton patterns, multithreading         |

##  Purpose

The purpose of this repository is to:

* Practise C++ programming through hands-on lab exercises.
* Build a strong foundation in Object-Oriented Programming.
* Understand modern C++ concepts through small, focused programs.
* Keep all semester lab work organized in one place.
* Maintain a record of progress throughout the semester.
* Strengthen problem-solving skills useful for coding interviews and placements.
